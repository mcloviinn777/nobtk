Installer NOBTK

La file d'attente de ton salon, sur ton téléphone. Version test.

ثبت NOBTK فالتيليفون ديالك

Sur Android

Télécharger NOBTK (APK)
  1. Touche le bouton vert, puis ouvre le fichier NOBTK.apk téléchargé.
  2. Si le téléphone demande, autorise « Installer des applis inconnues » pour Chrome ou WhatsApp. C'est normal pour une version test.
  3. Touche Installer, ouvre NOBTK et entre l'identifiant et le code de ton salon.

Sur iPhone

Ouvre cette page dans Safari : copie le lien et colle-le dans Safari. L'installation ne marche pas depuis Instagram ou Facebook.
Ouvrir NOBTK Barbier
  1. Touche le bouton noir : NOBTK s'ouvre dans Safari.
  2. Touche le bouton Partager en bas de l'écran.
  3. Descends et choisis « Sur l'écran d'accueil », puis « Ajouter ».
  4. Ouvre NOBTK depuis sa nouvelle icône et entre l'identifiant et le code de ton salon.

Garde NOBTK ouvert pendant que tu travailles : l'écran reste allumé tout seul.
